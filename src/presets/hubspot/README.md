# hubspot preset

HubSpot CMS theme development — HubL templating + fields.js.

## Install

```bash
aka-kit install --hubspot
aka-kit install --hubspot --platform all
```

## Adds (on top of shared)

- **3 skills** — hubspot-hubl, hubspot-fields-js, visual-diff-tester
- **1 rule** — hubspot-generator-rules.md

## When to use

Building HubSpot CMS themes, modules, or templates. Working with HubL syntax + fields.json / fields.js authoring.

## Skip if

Not a HubSpot project.
