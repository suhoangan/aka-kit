# php preset

PHP backend stack — Magento 2, Laravel, Symfony.

## Install

```bash
aka-kit install --php
aka-kit install --php --platform all
```

## Adds (on top of shared)

- **3 skills** — backend-development, ship-feature, php-code-reviewer (databases now in shared)

## When to use

Magento 2 modules / themes. Laravel applications. Symfony bundles. Any PHP codebase that benefits from MongoDB/PostgreSQL database guidance.

## Skip if

You're not writing PHP. (No frontend skills here — pair with `--nextjs` for full-stack.)
