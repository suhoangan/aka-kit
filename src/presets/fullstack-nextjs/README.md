# fullstack-nextjs preset

Named bundle: **nextjs** + all full-stack skills already in **shared** (databases, better-auth, payment-integration, deploy, devops, security-scan, docs).

## Install

```bash
aka-kit install --fullstack-nextjs
aka-kit install --fullstack-nextjs --platform all
```

## What you get

Everything from `--nextjs`, plus shared full-stack skills for auth, DB, payments, deploy, DevOps, security scan, and project docs.

## When to use

Building a production Next.js app with auth, database, and deployment — not just UI.

## When not to use

- Frontend-only prototype → `--nextjs`
- PHP/Magento backend → `--php`
- Node API without Next.js → `--node-backend`
